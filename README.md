Network Security Assessment & Security Architecture
Overview
This repository contains the group assessment for IE3122 – Network Security, Year 3 Semester 1. The assessment focuses on performing a network security assessment and designing a defense-in-depth security architecture for an organization with branch connectivity, remote access, public-facing services, and third-party integrations.

The work includes threat modelling, qualitative risk rating, technology evaluation, layered security planning, secure network architecture specification, and network security configuration with Packet Tracer evidence.

Description
The assessment required the group to:

Develop individual threat models using the chain: Asset → Vulnerability → Threat → Exploit → Attack → Impact → Risk

Apply a qualitative risk rating methodology and produce a consolidated threat register

Propose and evaluate security technologies across VPN, AAA, Secure Network Architecture, and IDS/IPS

Design a combined layered security plan with a master control list and control-to-threat mapping

Specify a secure network architecture with trust zones and logical traffic policy

Implement and verify network security configurations, including DHCP Snooping, Dynamic ARP Inspection, Native VLAN hardening, DTP disabling, Port Security, and Extended ACLs

Document implementation status, evidence, and remaining gaps
